# إنجاز | ENJAZ

تطبيق Android أصلي بـ Kotlin وJetpack Compose لتنظيم الدراسة والمهام والأهداف والتقارير، مع مدرب شخصي وإشعارات محلية.

## تحديث قائمة الإنجاز العامة
- إضافة عناصر من أي نوع: كورس، فيديو، تطبيق، عمل، فكرة أو شيء آخر.
- حفظ رابط وملاحظات لكل عنصر.
- تحديد تكرار التذكير من ساعة إلى أسبوع.
- تعليم العنصر كمكتمل لإيقاف تذكيراته، أو إعادته إلى القائمة.
- تذكيرات محلية ساخرة لا تتطلب خادمًا أو حسابًا.
- تُحفظ القائمة في SharedPreferences منفصل حتى لا تتغير صيغة ملف الدراسة القديم.

## الحفاظ على بيانات النسخ السابقة
اسم الحزمة ما زال `com.enjaz.app`. لا يُعاد إنشاء ملف الدراسة القديم ولا يُستبدل؛ قائمة الإنجاز لها مساحة تخزين مستقلة.

## البناء
GitHub Actions يبني APK تجريبيًا عند الدفع إلى `main` أو تشغيل workflow يدويًا.
